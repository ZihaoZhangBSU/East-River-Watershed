# East River Watershed

Figure-generation code.

- [Fig2_Watershed_SWE](Fig2_Watershed_SWE/): Figure 2, fractional watershed-area SWE means on the Noah-MP analysis grid, with unfiltered ASO remapping and explicit flight coverage. Includes validated extraction helpers and synthetic tests.

This repository upload contains source code, requirements, synthetic tests and usage instructions. Scientific input data and manuscript files are supplied separately by the author.
